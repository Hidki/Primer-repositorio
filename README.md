# Tarea PIA01 - Introducción a la Programación de Inteligencia Artificial

Este repositorio ha sido creado como parte de la primera tarea práctica del módulo **Programación de Inteligencia Artificial (PIA)**.

## Descripción de la tarea
El objetivo principal de esta práctica es habilitar un perfil técnico dentro del ecosistema de desarrollo de Inteligencia Artificial y familiarizarse con el uso de repositorios de control de versiones.

## Contenido del repositorio
* `README.md`: Documento redactado en lenguaje de marcación (Markdown) con la descripción de la actividad.
* `hola_mundo.py`: Primer script de prueba desarrollado en **Python**.
